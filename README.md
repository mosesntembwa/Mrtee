# Mrtee
Mr Tees AI is a 24/7 Digital Assistant created by Moses Ntembwa, an ICT student at Kapasa Makasa University. My aim is to make university information simple, fast and accessible for every student, helping Pre-Freshers with Admission, HELSB, Courses, Fees and Student Life. Ask anytime, anywhere. This is just the beginning for students across Zambia.
